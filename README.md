## 💻 Tecnologias Utilizadas

Para manter o projeto simples, rápido e fácil de rodar em qualquer máquina, utilizamos as seguintes tecnologias:

* **HTML5:** Estruturação semântica da página.
* **Tailwind CSS (via CDN):** Para a estilização moderna e responsiva sem a necessidade de configurações complexas no ambiente local.
* **Vanilla JavaScript:** Para as animações de scroll e comportamento do menu, mantendo o projeto leve e sem dependências pesadas.
* **Lucide Icons:** Biblioteca de ícones open-source.

## 🚀 Como executar o projeto

Como o projeto utiliza tecnologias web padrão, não é necessário instalar nenhum pacote ou servidor local complexo.

1. Clone ou baixe este repositório para o seu computador.
2. Navegue até a pasta do projeto.
3. Dê um duplo clique no arquivo `index.html` para abri-lo no seu navegador padrão.
